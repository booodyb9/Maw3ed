# مواعيد العلاج (Mawa'eed Ilaj) 🏥💊

تطبيق أندرويد متكامل وأصيل (Native Android) مبني بأحدث تقنيات **Kotlin** و **Jetpack Compose** و **Room Database** و **Material 3** لتنظيم مواعيد الكشف والزيارات الطبية والأدوية وتنبيهات الجرعات مع دعم تعدد الملفات الشخصية للعائلة ومرفقات الروشتات والتحاليل.

---

## 🌟 مميزات التطبيق

1. **إدارة مواعيد الكشف والزيارات الطبية:**
   - تسجيل اسم الموعد، الطبيب المعالج، التاريخ والوقت.
   - إمكانية تحديد موقع العيادة/المستشفى مع زر انتقال مباشر إلى تطبيق **خرائط جوجل (Google Maps)**.
   - جدولة تنبيهات متعددة مسبقة (قبل يوم، قبل ساعتين، قبل ساعة، قبل 30 دقيقة، في نفس الوقت).
   - خيارات تكرار الموعد (يومي، أسبوعي، شهري).

2. **تنظيم وجدولة الأدوية:**
   - تسجيل اسم الدواء والجرعة المطلوبة (مثال: قرص بعد الأكل).
   - إضافة أكثر من موعد جرعة في اليوم الواحد (صباحًا، ظهرًا، مساءً).
   - تحديد تاريخ بدء العلاج وتاريخ الانتهاء أو تعيينه كعلاج مستمر.
   - تنبيهات يومية بمواعيد كل جرعة.

3. **إدارة ملفات العائلة الشخصية (Profiles):**
   - دعم إنشاء ملفات متعددة (أنا، الأب، الأم، الزوج/الزوجة، الأبناء).
   - تصفية المواعيد والأدوية حسب كل شخص أو عرض الكل معًا.

4. **المرفقات الطبية والروشتات:**
   - إمكانية إرفاق صور الروشتات والتقارير الطبية ونتائج التحاليل وحفظها مباشرة داخل التطبيق مع عارض صور مدمج.

5. **نظام التنبيهات الموثوق:**
   - قنوات إشعارات مخصصة عالية الأهمية.
   - دعم إعادة جدولة التنبيهات تلقائيًا عند إعادة تشغيل الهاتف (`BOOT_COMPLETED`).

## 🚀 البناء التلقائي على GitHub (GitHub Actions)

المشروع جاهز ومزوّد بملف سير عمل تلقائي `.github/workflows/build.yml`. عند رفع الكود على GitHub، سيقوم الـ CI ببناء ملف الـ APK تلقائيًا وتوفيره للتحميل بدون الحاجة لتثبيت أي برامج على جهازك!

### خطوات الرفع على GitHub:

```bash
# 1. تهيئة المستودع
git init

# 2. إضافة كافة الملفات وعمل Commit
git add .
git commit -m "Initial commit: Native Android Mawaeed Ilaj app"

# 3. تسمية الفرع الرئيسي
git branch -M main

# 4. ربط المستودع بحسابك على GitHub (استبدل الرابط برابط مستودعك)
git remote add origin https://github.com/<USERNAME>/<REPO_NAME>.git

# 5. الرفع
git push -u origin main
```

### كيف تحمّل ملف الـ APK بعد الرفع؟
1. افتح صفحة المستودع على GitHub واضغط على تبويب **Actions**.
2. ستجد الـ Workflow بعنوان **Build Android APK**. اضغط على آخر تشغيل (Run).
3. بعد اكتمال البناء، ستجد في أسفل الصفحة قسم **Artifacts** وفيه ملف: `mawaeed-ilaj-apk`.
4. قم بتحميل الملف وفك ضغطه، وستجد ملف `app-debug.apk` جاهزًا للتثبيت مباشرة على أي هاتف أندرويد.

### نشر إصدار رسمي (Release):
عند عمل Tag جديد ورفعه:
```bash
git tag v1.0.0
git push origin v1.0.0
```
سيقوم GitHub تلقائيًا بإنشاء صفحة **Release** وإرفاق ملف الـ APK فيها مباشرة برابط تنزيل دائم.

## 💻 البناء والتشغيل محليًا (Local Build)

إذا أردت تشغيل المشروع أو بنائه على حاسوبك الشخصي:
```bash
# بناء نسخة التجربة (Debug APK)
./gradlew assembleDebug

# تثبيت التطبيق على جهاز متصل أو محاكي
./gradlew installDebug
```
